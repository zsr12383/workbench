# 예시 1: 설비 알람 대응 (모의 인터뷰)

숨은 사실 11개를 가진 가상 담당자에게 interview-me 방식(가설·추측, 3라운드)으로 물었다. 결과는 완전히 드러남 3, 일부 6, 놓침 2였다.

요청: "설비 알람이 뜨면 그동안 쌓인 로그를 학습한 AI 챗봇이 조치 방법을 바로 알려주게 해 주세요."

## 놓친 것과, 그것을 잡는 질문

| 놓친 사실 | 왜 놓쳤나 | 이 스킬의 질문 |
| --- | --- | --- |
| 오판하면 설비가 반나절~하루 서고 손실이 크다. 설비 개방·부품 교체는 엔지니어 승인, 안전장치 해제는 절대 안내 금지 | "범위 밖"만 묻고 오류 비용을 안 물음 | S7: "추천이 틀리면 무슨 일이 생기나요? 사람이 꼭 승인해야 하는 조치, AI가 절대 안내하면 안 되는 조치가 있나요?" |
| 정기 점검 직후 48시간 안의 알람은 조립 문제라 과거 이력 추천이 오히려 틀림 | 예외를 안 물음 | S8: "과거 기록대로 하면 오히려 틀리는 경우가 있나요?" |
| 노하우는 설비관리시스템보다 공유 드라이브의 인수인계 엑셀에 더 많음. 30%는 쓸모없는 기록, 사번·대외비 포함 | "A인가요, B인가요?"로 물어 제3의 출처가 안 나옴 | S4(열린 질문): "조치 노하우가 적혀 있는 곳을 전부 알려 주세요. 공식 시스템 밖의 파일도요. 양과 상태는요?" |
| 추천 상위 3개 안에 정답 70% 이상, 파일럿 3개월 | 성공 기준을 시간 하나로만 받음 | S3: "얼마나 빨라야 하는지와 함께, 얼마나 맞아야 성공인가요?" |
| 결과는 기존 시스템 입력 화면의 표준 코드(약 300개)로 들어가야 함 | "반은 맞아요", "창 하나 더는 안 써요"를 따라가지 않음 | 3절 전이: 부분 동의 → 틀린 반쪽을 다음 라운드 첫 질문으로 |
| 실제 사용자는 야간조 1~3년차, 장갑을 껴서 타이핑이 불편함 | "밤에 전화가 많아서요"라는 단서를 버림 | 3절 전이: 새 단서 → 다음 라운드에서 판다. S1의 몸 상태·숙련도 |
| 하루 25건, 60%가 야간, 최악은 2시간 넘음 | 평균 시간만 받음 | S2: "하루 몇 건이고, 가장 오래 걸린 경우는요?" |
| 딱 하나만 된다면 야간 호출 줄이기 | 우선순위를 안 물음 | S8: "딱 하나만 된다면 무엇인가요?" |

## 방향이 바뀌는 지점

R2에서 "외부 AI API 금지, 사내 LLM은 사무망, 현장 단말은 별도 망, 망 연계 승인 한 달"이 나왔다. 이것은 '챗봇'이라는 처음 해결책을 막는 제약이다. 3절의 "가설을 깨는 사실"에 해당하므로 4절로 간다. 현장 망 안에서 끝나는 방식을 만든다. 예: 알람 코드로 바로 시작하는 유사 이력 검색과 규칙, 기존 입력 화면 안의 코드 추천. 그다음 S7을 묻고 자동화 수준을 낮은 칸(찾아 보여 주기)에서 시작한다.

재진술에 "대체로 맞아요"가 돌아왔다. 이것은 확인이 아니다. "틀리거나 빠진 줄이 있다면 어디인가요?"를 한 번 더 물었어야 했다.

# 예시 2: 고객 문의 초기 회신 (이 스킬 v1로)

요청: "고객 문의가 들어오면 AI가 품질 보고서를 자동으로 써 주는 챗봇을 만들어 주세요."

숨은 사실 12개 중 완전히 드러남 7, 일부 4, 놓침 1(점수 75%)이었다. 예시 1은 11개 중 완전 3, 일부 6, 놓침 2(55%)였다. 시나리오가 다르고, 숨은 사실의 범주를 두 번 다 같은 목록으로 줬기 때문에 엄밀한 비교는 아니다.

잘 된 것:
- R1의 실제 사례 질문에서 "급한 건 보고서 전체가 아니라 초기 회신"이 나와 가설을 바로 고쳤다.
- 열린 데이터 질문으로 공식 시스템 밖의 개인 엑셀 600건(가장 정확)이 나왔다.
- "정확도는 당연히 높아야죠"를 숫자로 다시 물어 "10건 중 8건이 상위 5개 안"을 받았다.
- 오류 비용(영향 범위를 좁게 잡으면 큰 배상)과 '유사 사례'의 현업 뜻(문장이 비슷한 건이 아니라 불량 코드·제품 세대·원인 공정이 같은 건)을 받았다.

그래도 놓친 것과 고친 규칙:

| 놓친 것 | 고친 규칙 |
| --- | --- |
| 고객이 24시간 안에 초기 회신을 요구하고, 지금은 70%만 지킴(목표 95%) | S2·S3에 외부 기한과 준수율 |
| 문의의 20%는 협력 업체를 거쳐 와서 번호를 거슬러 찾아야 함. "이틀 넘게 걸린 건"이 이 경우 | 최악·이상치 → "그 건은 왜 그랬나요?" |
| 매일 쓸 사람은 당번 주니어 4명이고, 맥락을 몰라 하루 5~6번 물어 옴 | 추측이 "네"로만 맞으면 세부 하나 더 |
| 현업이 생각한 범위 밖(원인 분석 이후 단계, 대시보드, 이미지 판독)과 내가 정한 범위 밖이 따로 놂 | 범위 밖은 실무자에게 직접 묻는다 |
| 한 질문에 하위 질문이 많아 쉬운 쪽만 답함 | 라운드당 질문 3개, 질문당 하위 질문 2개 이하 |
